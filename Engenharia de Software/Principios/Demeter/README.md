### Demeter
O Princípio de Demeter estabelece que os métodos de uma classe devem utilizar apenas métodos da própria classe, parâmetros passados para esses métodos, objetos criados dentro dos métodos e atributos da classe. Essa prática ajuda a simplificar as interfaces, reduzir o acoplamento e tornar a manutenção mais simples.

No exemplo, é mostrado duas formas de como conseguir o modelo do carro de uma Pessoa, a forma errada acessa o Carro através do retorno de um método da classe Pessoa, essa forma fere o princípio de deméter porque permite que o carro seja acessado indiretamente pela classe Pessoa. A opção certa não fere o princípio porque implementa um método que acessa e retorna diretamente o modelo do carro, com isso o usuário não necessita saber da estrutura interna da classe Carro.
